OUR EVIDENCE STANDARD

A real screenshot
should tell the truth.

Decorative project artwork is not proof that a feature works. No new product screenshot has been presented as verified evidence without the genuine running application, the right to publish it, and a description of what was actually tested.

  1. Capture only authorized working interfaces.
  2. Hide passwords, private user information and unlicensed content.
  3. Record the tested feature and known limitations.
  4. Clearly label genuine captures versus illustrations.

Reported experiment results and repository observations are preliminary project records, not independent audit certificates.
