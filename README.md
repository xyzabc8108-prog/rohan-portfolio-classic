## Setup and deployment

The source is a static website at the repository root. There is no build step, paid API or backend required.

To publish through GitHub Pages:

1. In this repository open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main**, then **/(root)**, and **Save**.
4. Once Pages reports a successful build, open the website URL above.

For local testing, open `index.html` in a browser or serve this folder with any static HTTP server. The source assertions can be run with `node check.mjs`.
